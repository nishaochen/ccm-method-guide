## 1. 什么是结果关系结构

**结果关系结构**＝一项研究所涉及的结果数量，以及这些结果之间的关系形态。

它可以从「结果数量」与「结果关系」两个维度区分，形成五类基本类型（R1–R5）。这五类是**分析上的理想类型**，不保证穷尽，也不假设彼此排斥——同一研究问题可能同时涉及多种结构。

为什么它值得单独作为概念？因为因果复杂性的既有讨论几乎都集中在**原因侧**（合取性、析取性、非对称性，Mackie 1965；Misangyi 等 2017；Furnari 等 2021），而**结果侧**（产生几个结果、结果之间是并列、链式还是合取）长期未被理论化。结果侧复杂性对应的是「一因多果」（multifinality），与组态研究长期关注的「多因一果」（equifinality）形成对照。

诊断价值在于：**结果结构决定研究问题能否被某种方法在逻辑上表达**。这是方法的逻辑胜任边界，与样本量、噪声水平等经验边界是两回事。R3 结构下即使样本再大，QCA 和 CNA 也无法把 `Y1∧Y2` 当作一个整体结果来建模——这是表达能力的限制，不是数据质量问题。

## 2. R1–R5 逐类判定

### R1 单一结果

- **被解释对象**：`Y`
- **判定问句**：这项研究要解释的是一个结果，还是多个结果？
- **典型研究问题**：哪些条件组合导致某一结果出现或不出现？
- **方法**：QCA（连续程度或模糊隶属关系通常用 fsQCA）
- **要点**：研究问题本身并不要求方法同时表达多个结果之间的关系，因此 QCA 是直接且适宜的选择。解释多条组态时可结合核心／边缘条件、条件间的互补与替代关系、「组态生态学」等视角对不同组态做理论解释。
- **不要这样做**：为了方法创新而机械地把 QCA 换成 CNA。单结果情境下 QCA 与 CNA 在特定参数条件下可等价表达（Dușa, 2022），但二者并非在所有数据与参数下都一致——存在噪声、不同阈值设定时，QCA 简约解与 CNA 原子解会分岔（Haesebrouck & Thomann, 2022）。差异来源包括对逻辑余项、理论预期与最小化参数的不同处理（如 QCA 中间解可依理论预期约束逻辑余项，CNA 不以完全相同的方式处理这类信息）。

### R2 独立多结果

- **被解释对象**：彼此独立、分别建模的 `Y1` 与 `Y2`
- **判定问句**：这些结果之间，有没有你理论上需要解释的关系（因果、共同来源、须同步实现）？
- **典型研究问题**：研究者分别考察数字化转型对创新绩效与运营绩效的组态影响，但不试图解释二者之间的关系。
- **方法**：分别以不同结果为对象开展 QCA
- **要点**：**「多个结果」本身并不自动构成 QCA 的能力缺陷。** 真正需要改变方法的是结果之间存在需要被解释的结构关系。对 R2 而言，分别做 QCA 具有充分的合理性。
- **替代路线**：若研究重点随后转向「多个结果的共同前因」，则应改用 CNA。

### R3 结果合取

- **被解释对象**：`Y1 ∧ Y2`（整体结果）
- **判定问句**：研究关注的不是两个目标分别如何形成，而是「二者同时实现」需要什么条件组合？
- **典型研究问题**：企业同时实现经济绩效与环境绩效；平台同时实现规模扩张与生态健康；经济—社会—环境三重底线同步达成。
- **方法**：CORA
- **为什么只能是 CORA**：CORA 用多输出质蕴涵项（MOPI）做最小化，把「不可归约」的要求从单个结果提升到**整个结果系统**。CNA 虽然面向多结果，但在形成原子解时逐结果做输出级最小化，共享原因中那些对单个输出看似冗余的条件会被逐一删去——而这些条件在另一个输出那里可能是必需的。这一盲区是代数层面的：单输出最小化下，共享原因根本不会进入搜索空间。同一份数据，只因冗余的判定层级不同，结论可能完全相反。
- **数据约束**：CORA 目前只支持清晰集与多值集。模糊集需先二值化或多值化，并报告切点与边界值归向。因此，**结果结构决定 CORA 的必要性，数据形态决定其可行性**。
- **计算约束**：CORA 用 Petrick 方法，计算复杂度随各输出的质蕴涵项数量呈乘性增长。大样本、高噪声下可能超时（Hou 等 2026 的 15 000 个仿真数据集中约 8.9% 因超时未能给出解）。凡建立在二值化切片上的 CORA 结论都应显式报告切点。

### R4 因果链

- **被解释对象**：`X→M→Y` 中的层级关系，M 既是上游组态的结果，又是下游结果的原因
- **判定问句**：多个结果之间是否存在时间或理论上的先后，且前者可能构成后者的原因？
- **典型研究问题**：组织文化→创新障碍→创新绩效；财政科技投入→协同创新→经济绩效
- **方法**：
  - **结构发现** → CNA（可依据理论与时间顺序给出大致层级，由数据识别具体因果链与共同原因）
  - **理论检验** → 复杂中介模型 / 两阶段 QCA（已明确提出中介机制、要分阶段检验时）
- **要点**：分别对每个结果做 QCA、再把各阶段人为连接，容易割裂跨阶段关系，也难以直接识别整体因果结构。但分阶段方法并非一无是处——它们能给出净效应估计与逐链的必要性／充分性检验。
- **措辞红线**：CNA 呈现的是链式结构与直接路径并存的多路径结构时，不要把整个系统概括为「稳定的线性中介机制」。CNA 识别的是组态结构位置，不是回归意义上的中介效应。

### R5 共同原因

- **被解释对象**：同一条件 X 同时指向 `Y1` 与 `Y2`
- **判定问句**：是否存在一个条件，理论上同时驱动两个结果？
- **典型研究问题**：高管支持既促进运营效率又促进创新绩效。
- **方法**：CNA
- **为什么**：分别做 QCA 只能得到两个相互独立的解，无法直接识别 B 是连接多个结果的共同原因；两个独立解可能掩盖真实的因果网络结构。CNA 的复杂解公式（CSF）中，中介结果身兼二职，正是把多个结果组织成因果网的能力所在。

## 3. 边界情形

**（1）同一研究问题涉及多种结构。** 例如既关心「哪些条件让 ESG 三维同时达标」（R3），又关心「环境绩效是否进一步影响财务绩效」（R4）。处理方式：
- 并列报告两种结构的分析结果，各自交代其被解释对象与方法；
- 或在理论支持下采用方法组合。**不要**把两种结构硬塞进一个模型。

**（2）结构随研究问题而变。** 同一批数据、同一组前因条件，只改变被解释对象，结果结构与方法选择就变了。这是本框架最有说服力的演示方式：在数据、条件集和样本保持一致的前提下，仅改变结果关系结构，方法便由 fsQCA 转向 fuzzy CNA 再转向 CORA。示范见 `worked-example.md`。

**（3）结果合取与因果链的区分。** 若两个结果取自**不同年份**，那实质是「先后实现」而非「同时实现」——此时它更接近 R4，而不是 R3。这是最容易出错的一处，务必核年份。

**（4）独立性是理论判断，不是统计判断。** 「彼此独立」指的是研究者**不打算解释**其关系，而不是「相关系数低」。若两个结果在理论上显然相互影响，即使统计上相关很弱，也应归入 R4/R5。

**（5）方向性断裂可以是亮点。** 同一条件让 A 出现、让 B 不出现的「跨结果对称性断裂」，不是缺陷，反而是结果侧复杂性的重要发现——它对应组态因果的非对称性。

**（6）面板数据的案例独立性。** 多年观测**不能池化**成一个「大样本」当作相互独立的案例。312 家企业 × 6 年 = 1 872 个企业-年进入分析，会造成伪重复：覆盖数、组态内比例等一切按案例计数的指标都会虚高，可靠性被高估。正确做法是先把数据压成**一行一家企业的横截面**——条件取多年均值（或理论指定的基期），若做结果合取则两个结果**同取某一年**（通常取末年）；分年度切片只作为稳健性检验，不作主分析。

**（7）时间窗口的选取本身是一个设计决策。** 用哪一年、滞后几期、是否取均值，都会改变被解释对象。选定后必须在正文交代依据，并说明它排除了什么、没排除什么（时间倒置可以排除，共同前因、样本选择与测量误差不能）。

## 4. 常见误判清单

| 误判 | 为什么错 | 怎么纠正 |
| --- | --- | --- |
| 有多个结果 → 用 CNA/CORA | 结果数量不是判据，结果**关系**才是 | 先问关系，独立的多结果分别做 QCA 即可 |
| 中介问题 → 拆成 R2 分别做 QCA | R2 是「结果之间**无需解释**的关系」；中介链条上的结果之间有明确的先后与层级，属 **R4 因果链**。按实现方式把它划归 R2 是错的口径 | 判为 R4，再按研究目的分流：理论检验走分阶段方法，结构发现走 CNA（下文第 4 问） |
| 结果合取用不同年份的结果 | 「同时实现」被偷换成「先后实现」 | 两个合取结果必须同年 |
| 用 QCA 跑结果合取 | QCA 无法把 `Y1∧Y2` 作为整体结果最小化 | 换 CORA，或退回 R2 分别建模并说明局限 |
| 为了用 CORA 把连续变量机械二值化 | 数据形态不应反向改变研究问题或结果结构 | 先确认 R3 成立，再二值化并报告切点 |
| 把「多个结果」拆成若干个单结果 QCA 就宣布解决了多结果问题 | 跨结果的结构冗余与虚假关联仍存在 | 若关系确实需要解释，改用 CNA/CORA |
| 拿 CORA 的 con 与 fsQCA 的 inclS 比大小 | 三者一致性口径不同 | 跨方法只比较「结构结论」是否一致，不比数值 |
| 单结果场景为求新换成 CNA | 二者在特定条件下等价，不存在简单优劣 | 保持 QCA；如需交叉验证可并跑 CNA 并报告分岔条件 |

## 5. 判定问句速查

按顺序问，问到「是」就停：

0. 这项研究问的是**平均净效应**，还是**条件组态**？
   - 平均净效应 → 回归／SEM 等变量导向方法，**不属 CCM**，到此为止
   - 条件组态 → 第 1 问
1. 这项研究要解释的**结果有几个**？
   - 一个 → **R1**，QCA/fsQCA
   - 多个 → 第 2 问
2. 这些结果之间，有没有**理论上需要解释**的关系？
   - 没有 → **R2**，分别做 QCA
   - 有 → 第 3 问
3. 是**必须同步实现**吗？
   - 是 → **R3**，CORA
   - 不是 → 第 4 问
4. 是**先后／层级**关系（一个结果又是后续结果的原因）吗？
   - 是 → **R4**，再看研究目的是理论检验（分阶段方法）还是结构发现（CNA）
   - 不是 → **R5**（同一条件同时驱动多个结果），CNA

问完结构，再问数据条件（见 `design-checklist.md` 第一节）。
