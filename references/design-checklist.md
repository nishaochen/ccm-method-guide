# 多结果 CCM 设计检查清单

> 用法：走完选型（`SKILL.md` 五步）后逐节过一遍。每节末尾给出**该写进论文的位置**。
> 顺序不可颠倒——这是本清单唯一的硬要求：**先定结构，再选方法，最后检验数据条件。**

---

## 一、结果结构界定

- [ ] 明确研究问题中的结果变量**数量**及其**关系形态**
- [ ] 按「结果数量 × 结果关系」两个维度判定为 R1–R5 中的哪一类（或哪几类并存）
- [ ] 确认这五类是分析上的**理想类型**，不保证穷尽或互斥
- [ ] 若涉及多种结构：决定是分别报告，还是在理论支持下采用方法组合
- [ ] 写下判定所依据的**研究问题原话**——结构判定要能回溯到研究问题，而不是从变量表倒推

**写进论文**：研究设计与方法一节的开头，作为方法选择的依据（而不是作为「方法介绍」的附属说明）。

---

## 二、方法与结果结构匹配

- [ ] 单一结果 → QCA/fsQCA
- [ ] 有层级或链式关系 → CNA；若理论预设明确且须分阶段检验，则复杂中介／两阶段 QCA
- [ ] 多个结果需同步实现 → CORA
- [ ] 彼此独立的多个结果 → 分别建立单一结果模型；若重点转向共同前因结构 → CNA
- [ ] 已检查**没有**为了某种方法的计算便利而反向调整研究问题

**写进论文**：一段方法选择理由，明确「结构 → 方法」的对应，并说明没有采用替代方法的理由。

---

## 三、条件数量、构念构造与案例独立性

`k ≤ N/4` 只是起点，它通过不代表条件集可用。下面三项要一起查：

### 3.1 条件数量
- [ ] 检查 `k ≤ N/4`（k 为前因条件数，N 为有效案例数）。这是操作性控制标准，不是统计定理
- [ ] 超出范围时，**依据理论意义**删除冗余或高度重叠的条件
- [ ] 没有通过机械降低一致性阈值来「扩大可识别空间」
- [ ] 检查各条件高／低集合的案例分布，确认没有条件缺乏经验变异
- [ ] 检查理论真值表行的**经验覆盖**：`2^k` 行 vs 案例数，平均每行不足 1 个案例时有限多样性明显，须报告并考虑精简条件

### 3.2 构念是否可直接当条件（最容易漏的一步）
- [ ] 每个「条件」是不是一个**可拆分的多维构念**？若把多维度量表整体合成一个变量，`k` 会退化
- [ ] 极端情形：自变量只有一个合成变量 → `k = 1`、真值表仅 2 行，**根本没有组态可言**
- [ ] 量表的子维度之间若理论上可分，应按维度拆成多个条件再入模；若要合成，须说明为何该构念在理论上不可分
- [ ] 条件之间高度重叠时，宁可依据理论保留其一，也不要同时放入

> 为什么单列一条：审查「条件数量」时看的是 `k` 的绝对值，
> 而构念合成问题会让 `k` 在**不知不觉中**变小——把 4 个维度合成 1 个变量，等于把 4 个条件压成 1 个，
> 组态分析的立论基础随之消失，但表面上看 `k ≤ N/4` 完全合格。

### 3.3 案例独立性（面板/多层数据）
- [ ] 多年观测**没有**被池化成一个大样本直接入模（伪重复会虚高覆盖数与组态内比例）
- [ ] 已把数据压成**一行一家企业**的横截面：条件取多年均值或理论指定基期；做结果合取时两个结果**同取某一年**
- [ ] 分年度切片／分行业子样本只作为稳健性检验，不作主分析
- [ ] 时间窗口的选取依据已写进正文（用哪一年、是否滞后、为何取均值）

**写进论文**：数据与测量一节的预检段落 + 时间窗口的选取依据。

---

## 四、校准与数据形态

- [ ] 连续变量原则上采用**模糊集校准**，保留连续信息
- [ ] 校准锚点有明确的理论或经验依据；报告锚点值
- [ ] 小样本或量表型变量**没有**机械套用 P5/P95：N 小时分位数锚点随抽样抖动，
      应优先用理论锚点（如 7 点量表 6/4/2 或 7/4/1），并以分位数锚点作敏感性对照。
      注意量表中点（7 点量表的 4）若恰为 P50，会制造大量隶属度 0.5 的案例。
      详见 `method-specs.md` 的「小样本与量表型变量的锚点怎么选」
- [ ] 多题项构念先算维度均值再校准；未用线性归一化（如 `(x−1)/6`）冒充校准
- [ ] 通过改变校准锚点考察结果敏感性（如 P5/P50/P95 ↔ P10/P50/P90）
- [ ] 只有在理论分类、方法要求或稳健性检验有明确依据时，才转为清晰集／多值集
- [ ] **没有**为了适应 CORA 的数据形式而把原始连续变量机械二值化
- [ ] 报告**各变量隶属度恰为 0.5 的案例数**，并说明处理方式：
  - fsQCA：剔除**结果变量**的 0.5 案例；以前因条件为对象时，报告边界案例在真值表中的归属及其对解的影响
  - CORA 等清晰集方法：事先说明二值化切点、边界值归入方向及其作用范围
  - CNA：可保留
- [ ] 用改变边界值归属或调整切点的方式检验结论是否变化，并一并报告

> 为什么这条这么重要：直接校准法以中位点锚定 0.5，原始值恰等于 P50 的案例会落在边界上；
> 变量越多、原始取值越离散（例如整数打分），落在 P50 上的案例就越多，量级可能不小。不报告会被审稿人抓住。

**写进论文**：校准方案一节 + 「数据质量与组态结构预检」段落。

## 五、必要性初检

- [ ] 在充分性组态分析之前，按理论判断对候选条件进行必要性检验
- [ ] 报告各条件的必要性一致度（`inclN`）、覆盖度（`covN`）与 RoN
- [ ] 注意区分 **inclN 与 covN**——「一致度最高」与「覆盖度最高」是两回事，别标错行
- [ ] 未因某条件反复出现在充分组态中，就直接把它解释为必要条件
- [ ] 有明确必要性判断时采用 NCA，并说明 NCA 与 QCA 必要性检验回答的是不同问题
- [ ] 若结论是「没有条件接近必要条件判定标准」，注意措辞边界：这不等于「不存在任何必要性约束」，也不宜据此推断 NCA 不适用

**写进论文**：必要性分析小节（可与数据预检合并）。

## 六、主分析与结果报告

### 通用
- [ ] 报告软件及版本、样本筛选口径、变量定义与测度、校准锚点、全部阈值参数
- [ ] 正文、图表与附录中的**样本量、参数与指标保持一致**（交叉核对！）
- [ ] 提供完整分析输出或注明获取方式，以支持复现

### fsQCA
- [ ] 校准锚点及依据、频数阈值、一致性阈值、PRI 标准
- [ ] 逻辑余项处理方式、所报告的解类型（复杂解/简约解/中间解）
- [ ] 各路径的 inclS、PRI、covS、covU 与总体解指标
- [ ] 边界案例（0.5 隶属度）的处理规则及其对解的影响

### CNA
- [ ] 因果排序的**依据**（理论 + 时间逻辑），并声明排序只是搜索约束
- [ ] 搜索约束（是否冗余自由、是否只输出最小充分条件集合）
- [ ] 一致性 con 与覆盖度 cov 的准入阈值
- [ ] 各结果的最小充分条件、以及结果之间的结构关系
- [ ] 解的非唯一性

### CORA
- [ ] 二值化或分值的设定（切点、边界值归向）
- [ ] 一致性阈值 `inc_score`
- [ ] 能够共同覆盖多个结果的充分条件及其对应的输出
- [ ] 组态内部比例类指标给出**分子、分母与计算对象**
- [ ] 说明质蕴涵项覆盖的案例可以重叠，不构成对样本的划分

> 不同方法的指标具有不同的逻辑含义，**不能仅凭一致度或覆盖度的数值大小做跨方法比较**。

**写进论文**：结果一节 + 各表表注。

## 七、稳健性检验与跨方法对照

- [ ] **一致性阈值**：在合理范围内调整，考察核心组态及结构结论是否实质变化
- [ ] **校准方式**：改变锚点检验结果对校准的敏感性
- [ ] **数据形态**：必要时比较不同数据形态下的分析结果（如 CNA 的清晰集 vs 模糊集）
- [ ] 阈值敏感性**分档报告**，并区分两类结构：
  - 多个阈值下稳定出现 → 可作为稳健结论
  - 仅在特定阈值下出现 → 说明其成立条件，并**降低在结论中的权重**
- [ ] 紧贴阈值边界的结构，在正文明确交代其随阈值提高而变化或消失的条件，不表述为稳定发现
- [ ] 跨方法对照**以研究问题和结果结构的一致性为基础**，不比较方法优劣
- [ ] 不同方法识别出的相同条件，没有被直接视为具有相同的统计含义

**写进论文**：稳健性检验小节 + 结论节的证据边界段落。

---

## 八、结论措辞的证据边界

按证据强度分级措辞，避免越界：

| 证据 | 可以说 | 不能说 |
| --- | --- | --- |
| 稳定出现在多种组态中的条件 | 稳定的**组态基础** | 必要条件 |
| 形成充分关系的组态 | **充分性**证据 | 决定性作用 |
| CNA 识别出的链式结构 | 与设定排序相一致的**组态结构位置** | 完整的线性中介过程 / 因果效应 |
| CORA 识别出的双输出质蕴涵项 | 结果**协同**组态 | 两个结果的简单相加 / 唯一实现路径 |
| 时间排序 | 排除了时间倒置 | 排除了共同前因、样本选择、测量误差 |

---

## 九、跨方法对照该怎么做（一个稳妥的组合设计）

若研究问题确实涉及多种结果结构，最稳的设计是：

1. **fsQCA 主分析**——回答单一结果的充分组态；
2. **CNA 交叉验证**——两条独立的算法路线得到一致结论，构成强稳健性论证；不一致则是有价值的方法学发现；
3. **CORA 补充复杂效应**——展示「同时实现」需要什么，这是 QCA 与 CNA 问不出来的。

三者的被解释对象不同，因此**并列报告**而非互相替代。正文要写清三组分析的被解释对象、样本口径与阈值设定各是什么，以及为什么差异仅来自结果关系结构。
